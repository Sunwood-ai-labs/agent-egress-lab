# v0.1.0 — Initial release

![Agent Egress Lab v0.1.0 release header](/release-header-v0.1.0.svg)

Agent Egress Lab v0.1.0 is the first public release. With no previous tag, these notes cover the complete history shipped in this version.

## Highlights

- **Default-deny agent egress:** the agent container is attached to an internal Docker network and has no direct public route.
- **Explicit proxy path:** a dual-homed CONNECT-only test proxy permits configured `host:port` targets and rejects other targets.
- **Offline Playwright E2E:** the browser runner loads an internal test page while public navigation fails with real Chromium evidence.
- **Repeatable verification:** PowerShell scripts assert all expected outcomes instead of relying on manual observation.

## Documentation and evidence

The release includes bilingual operator documentation, an editable draw.io architecture diagram, JPG and SVG exports, a curated Chromium failure screenshot, and a local verification report.

Read the [v0.1.0 walkthrough](../guide/articles/v0.1.0-walkthrough) for a guided tour of both experiments.

## Validation

The release process runs:

- `./verify.ps1`
- `./verify-offline-e2e.ps1`
- Python unit tests for allowlist parsing
- `docker compose config` for both Compose files
- `npm run docs:build` in `docs/`

## Important limitation

Destination allowlisting reduces reachable paths but cannot prevent data from leaving through an allowed destination. The bundled proxy is deliberately a test fixture and must not be treated as a production security boundary.
