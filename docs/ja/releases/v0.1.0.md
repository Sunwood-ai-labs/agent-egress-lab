# v0.1.0 — 初回リリース

![Agent Egress Lab v0.1.0 リリースヘッダー](/release-header-v0.1.0.svg)

Agent Egress Lab v0.1.0は最初の公開リリースです。以前のタグがないため、このリリースノートは本バージョンに含まれる全履歴を対象とします。

## ハイライト

- **Agent egressのデフォルト拒否：** AgentコンテナをDocker内部ネットワークへ接続し、公開インターネットへの直接経路をなくしました。
- **明示的なプロキシ経路：** 二重接続のCONNECT専用テストプロキシが、設定済み`host:port`だけを許可し、その他を拒否します。
- **Offline Playwright E2E：** ブラウザRunnerは内部テストページを表示できる一方、公開ページへの遷移は実際のChromium証拠付きで失敗します。
- **繰り返し可能な検証：** PowerShellスクリプトが期待結果をassertし、目視だけに依存しません。

## ドキュメントと証拠

日英の運用ドキュメント、編集可能なdraw.io構成図、JPG/SVG出力、Chromiumの失敗スクリーンショット、ローカル検証レポートを同梱します。

2つの実験を順に確認する場合は、[v0.1.0 ウォークスルー](../guide/articles/v0.1.0-walkthrough)を参照してください。

## 検証

リリース工程では次を実行します。

- `./verify.ps1`
- `./verify-offline-e2e.ps1`
- 許可リスト解析のPython unit test
- 2つのComposeファイルに対する`docker compose config`
- `docs/`での`npm run docs:build`

## 重要な制限

接続先の許可リストは到達可能な経路を減らしますが、許可済み接続先を経由したデータ送信までは防げません。同梱プロキシは意図的に小さなテストフィクスチャであり、本番向けセキュリティ境界として扱わないでください。
